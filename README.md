## ⚡️ كيفاش تبدّل رقم الواتساب (الأهم)

حلّ ملف `Index.html` و ابحث على **`BH_CONFIG`** (فوق في الـ `<script>`):

```js
const BH_CONFIG = {
  whatsapp:     "213555000000",   // 👈 بدّل هذا
  phoneDisplay: "+213 555 000 000",
  email:        "orders@bhfight.co",

  brand:   "BH FIGHT CO.",
  product: "BH PRO-01 Pro Training Gloves",
  currency:"DZD",

  // الأسعار
  pricePerPair: 7900,   // زوج واحد
  bundle2:      14500,  // زوجين (Double Pack)
  bundle3:      20900,  // 3 أزواج (Gym Pack)
  extraPair:    6967,   // الزوج الرابع والخامس (سعر الكلوب)

  freeShipFrom: 0,      // 0 = التوصيل مدفوع. حط 20000 = توصيل مجاني فوق 20,000 دج

  // التوصيل حسب المنطقة
  zones: {
    1: { label: "Alger & environs",     price: 400  },
    2: { label: "Nord / Est / Ouest",   price: 600  },
    3: { label: "Hauts plateaux & Sud", price: 800  },
    4: { label: "Grand Sud",            price: 1000 }
  }
};
```

**رقم الواتساب يكون بالصيغة الدولية و بلا علامات:**
- الرقم `0555 12 34 56` → تكتبو `213555123456`

كي تبدّلو، **كل** أزرار الصفحة يتحدثو وحدهم.

## 🚚 التوصيل حسب الولايات (58 ولاية)

الـ `<select>` تاع الولايات يتولد تلقائياً من مصفوفة `WILAYAS` (في الـ JavaScript):
كل ولاية عندها **الكود + الاسم بالفرنسية + الاسم بالعربية + رقم المنطقة**:

```js
{c:16, fr:"Alger",      ar:"الجزائر", z:1},   // نخبة 1 → 400 دج
{c:36, fr:"El Tarf",    ar:"الطارف",  z:2},   // نخبة 2 → 600 دج
{c:11, fr:"Tamanrasset",ar:"تمنراست", z:4},   // نخبة 4 → 1000 دج
```

تقسيم المناطق (بدّل براحتك في `zones` و في `z` تاع كل ولاية):

| المنطقة | الولايات | السعر |
|---|---|---|
| **Zone 1** | Alger 16 · Blida 09 · Boumerdès 35 · Tipaza 42 | **400 DZD** |
| **Zone 2** | الشمال، الشرق و الغرب (Oran 31، Constantine 25، Annaba 23، Sétif 19، El Tarf 36، Tizi Ouzou 15، Béjaïa 06 … 23 ولاية) | **600 DZD** |
| **Zone 3** | الهضاب و الجنوب القريب (Batna 05، Biskra 07، Tébessa 12، Djelfa 17، M'Sila 28 … 13 ولاية) | **800 DZD** |
| **Zone 4** | الصحراء الكبرى (Adrar 01، Tamanrasset 11، Illizi 33، Ouargla 30، Tindouf 37 … 18 ولاية) | **1000 DZD** |

**المعادلة:** `Total = (السعر الأساسي × الكمية) + التوصيل` — تتحدث **فورياً** كي تبدّل الولاية، الكمية، المقاس ولا اللون.

> ⚠️ الأسعار نموذجية. عيّنها كيفاش يتعاملو معاك شركات التوصيل (Yalidine, ZR Express…) — بدّل غير الأرقام في `zones`.

## 🧾 فورم الطلب (Checkout)

الليبلات بالدارجة/الفرنسية، و باقي الصفحة بالإنجليزية (كيما مطلوب):

| الحقل | Label | إلزامي |
|---|---|---|
| الاسم | `Nom & Prénom / الاسم واللقب` | ✅ |
| الهاتف | `Numéro de téléphone / رقم الهاتف` | ✅ (10 أرقام، يبدا بـ 05/06/07، ولا `+213`) |
| الولاية | `Wilaya / الولاية` | ✅ |
| العنوان / ملاحظة | `Adresse / ملاحظة` | ❌ (اختياري) |
| الزر | `Valider la commande sur WhatsApp / تأكيد الطلب عبر واتساب` | — |

كي يغلط الكليان، تظهرلو رسالة خطأ تحت الحقل (بالفرنسية + بالعربية) و ما يتصيفطش الطلب.
كذلك الفورم يقبل غير الأرقام الجزائرية الصحيحة (05/06/07 + 8 أرقام).

# BH FIGHT CO. — لندينغ باج تاع قفازات الملاكمة

صفحة هبوط (Landing Page) كاملة، ملف واحد `Index.html` + مجلد `assets` فيه الصور.
بلا أي مكتبة خارجية — HTML / CSS / JavaScript خالص، يعني تخدم مباشرة بلا build.

---

## ⚡️ كيفاش تبدّل رقم الواتساب (الأهم)

حلّ ملف `Index.html` بالـ Notepad ولا VS Code، و روح لتحت للـ `<script>`.
أول بلوك فيه:

```js
const BH_CONFIG = {
  whatsapp: "213555000000",          // 👈 بدّل هذا
  phoneDisplay: "+213 555 000 000",
  email: "orders@bhfight.co",

  pricePerPair: 7900,
  shipFlat: 600,
  freeShipFrom: 10000,
  shipNote: "Free delivery above 10,000 DA"
};
```

**رقم الواتساب يكون بالصيغة الدولية و بلا علامات:**
- الرقم تاعك مثلاً `0555 12 34 56` → تكتبو `213555123456`
- يتسمى: كود الدولة (213 لتاع الجزائر) + الرقم بلا الصفر و بلا مسافات.

كي تبدّلو، **كل** أزرار الصفحة (زر الـ Header، الهيرو، الأزرار الطايرة، السطر السفلي، و
باني الطلب) يتحدثو وحدهم.

### تبديل الأسعار
في نفس البلوك: `pricePerPair` سعر الزوج الواحد، `shipFlat` سعر التوصيل،
و `freeShipFrom` السومة اللي فوقها التوصيل مجاني.

أسعار الباقات (2 أزواج = 14,500 دج / 3 أزواج = 20,900 دج) موجودة في دالة
`computeTotals()` — تلقاهم كي تبحث على `20900` و `14500`.

كذلك تبدّل الأسعار المكتوبة في جدول `#pricing` يدوياً.

## 🎨 الألوان

أسود رياضي (`#08080b`) + أحمر قوي (`#e5122b`) — تقاليد البوكسينغ.
تلقى الألوان كامل في `:root` فوق في الـ CSS. تبدّل `--red` وتتبدل الصفحة كامل.

الخطوط: `Oswald` للعناوين (style رياضي) و `Inter` للنصوص، من Google Fonts.

## 🚀 كيفاش تحطها في الأنترنت (بلا فلوس)

1. **GitHub Pages** — حط الملفات في ريبو public، دير `Settings → Pages → Deploy from branch → main / root`.
2. **Netlify** — اسحب مجلد المشروع كامل على [netlify.com/drop](https://app.netlify.com/drop). يخدم في ثانية.
3. **Vercel** — نفس الشي، ولا تربطو بالريبو تاع GitHub.

> ملاحظة: الصفحة تربط لصور موجودة في `assets/` — يعني لازم ترفع المجلد كامل،
> ماشي `Index.html` وحدو.
